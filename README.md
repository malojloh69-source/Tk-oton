# ТК OTON

Сайт транспортной компании: грузоперевозки по России, подбор транспорта и предварительный расчёт стоимости.

## GitHub Pages

Сайт не требует сборки. В **Settings → Pages** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, затем нажмите **Save**.

На GitHub Pages Python-сервер не запускается: онлайн-маршруты запрашиваются браузером напрямую у Photon и OSRM. Если внешний сервис недоступен, расстояние можно указать вручную. Заявка копируется или скачивается для передачи перевозчику; автоматической отправки нет.

## Локальный запуск

```bash
python3 main.py
```

Откройте http://localhost:3000. Локальный сервер также предоставляет кеширующий прокси для построения маршрутов.

Тарифы: `tariffs.js`. Инструкции: `README_START.txt` и `NASTROYKA_TARIFOV.txt`.
